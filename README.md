# Машин хрю-дневничок 🐷🌷

Личный Telegram-бот на aiogram 3: дневник цикла, самочувствия и отношений с розовым календарём и свинкой. Работает только в личных чатах двух разрешённых аккаунтов.

## Что умеет

- Несколько симптомов одним набором: выбрать кнопками, добавить свои через запятую, нажать «Сохранить выбранное».
- 20 вариантов симптомов и 17 вариантов настроения; настроение, самочувствие, близость, секс и заметки допускают свободный текст.
- Несколько отдельных событий одной категории за день, с временем. Новые записи не перезаписывают предыдущие. Время можно выбрать или ввести; для прошлых дней оно изначально не указано.
- Боль от 1 до 10 и «Нет боли»; после симптомов предлагается оценить боль. Интенсивность выделений отмечается отдельной категорией.
- «Начались» и «Закончились»: месячные заполняются между датами включительно. До отметки окончания активный период продолжается до сегодняшнего дня. Конец — последний день кровотечения. Есть исправление границ и добавление завершённых прошлых периодов.
- PNG-календарь со свинкой: фактические месячные, близость и секс; приблизительное окно следующего начала выделено отдельно. Текст о сексе/близости считается событием, «Нет» не создаёт отметку. Несколько событий в день независимы: «Нет» в новой записи не отменяет предыдущую «Да» — для этого исправьте или удалите прежнее событие.
- Статистика за 90 дней: частые симптомы, настроение и последние изменения настроения, средняя боль за день с графиком. Пустые дни не считаются нулевой болью. Длительность завершённых месячных и последние интервалы циклов считаются по всей истории.
- Приблизительный прогноз после трёх циклов: медиана последних шести интервалов и окно с учётом разброса (не уже ±2 дней). Просроченное окно автоматически вперёд не сдвигается. Это описательная оценка, не медицинский диагноз и не метод контрацепции.
- Исправление текста/времени отдельной записи, удаление с подтверждением и отмена последних 20 изменений, включая изменения периодов. Отменённые действия не имеют функции «повторить».
- Ежедневное напоминание Маше, выбор времени, отключение, «Через час». Настройки сохраняются в базе. Пока бот не работает, уведомления не отправляются; при запуске после выбранного времени приходит одно напоминание за текущий день. Ошибки отправки повторяются не чаще раза в пять минут. Рекомендуется один процесс бота.

## Доступ и обмен

Обмен **всегда включён**: партнёр видит весь дневник и получает уведомления о добавлении, исправлении, удалении и отмене записей. `/share` показывает эту информацию и не отключает обмен. Оба пользователя должны открыть бота и нажать `/start`. Изменять дневник и настройки напоминаний может только Маша.

Уже отправленные Telegram-сообщения не удаляются при удалении или отмене записи. Недоставленное уведомление о записи автоматически не повторяется, но актуальная запись остаётся доступна в дневнике. Напоминания отправляются только Маше. Изображения строятся локально, без внешних сервисов.

## Установка и запуск

Python 3.12+. Создайте бота через @BotFather. Задайте `BOT_TOKEN` в защищённых переменных процесса, не в коде или чате. `.env` автоматически не читается.

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py
```

На Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

| Переменная | Значение по умолчанию |
| --- | --- |
| `BOT_TOKEN` | Обязательный токен от BotFather |
| `BOT_TIMEZONE` | `Europe/Moscow`, для дат и напоминаний |
| `BOT_DB` | `data/diary.sqlite3` |
| `MASHA_ID` | `8651332701` — сохранён тестовый аккаунт из предыдущей версии репозитория |
| `PARTNER_ID` | `1307205193` |

Для аккаунта Маши из первоначальной настройки задайте `MASHA_ID=1842996053` на хостинге. Настройки доступа меняются после перезапуска.

Для хостинга: установка `pip install -r requirements.lock`, запуск `python bot.py`. Нужен HTTPS к `api.telegram.org`; webhook этого бота должен быть отключён. Запускайте один экземпляр. Шрифт с кириллицей и его лицензия включены в `assets`, дополнительная установка системных шрифтов не нужна.

## Обновление существующего бота

1. Остановите старый процесс; сохраните имеющийся файл базы и его путь `BOT_DB`.
2. Обновите код и установите зависимости из `requirements.lock` (включая Pillow).
3. Запустите один экземпляр новой версии. Таблица старых дневных отметок переносится в события транзакционно и только один раз; исходные даты, категории и значения сохраняются. Старая таблица удаляется после переноса. Старые дневные отметки месячных остаются отдельными редактируемыми записями.
4. Команды Telegram зарегистрируются автоматически. Старые inline-кнопки предложат открыть новое меню через `/start`.

**Не удаляйте `data` при развёртывании.** Используйте постоянный диск хостинга для `BOT_DB`: код не заменяет постоянное хранилище. Версия меняет схему базы; старую версию нельзя запускать поверх обновлённой базы. SQLite не шифруется приложением. История отмены содержит до 20 снимков дневника, в том числе после `/erase`, чтобы можно было восстановить случайно удалённое. Автоматических внешних резервных копий нет.

## Команды

Команды доступны в меню у поля ввода. Даты для действий выбираются кнопками «Сегодня», «Вчера» и календарём; месяцы календаря переключаются кнопками.

- `/start` — главное меню и информация об обмене.
- `/record` — добавить событие.
- `/period` — начало, конец, история и исправление месячных.
- `/day` — записи выбранного дня.
- `/calendar` — календарь-картинка.
- `/stats` — статистика и график боли.
- `/forecast` — приблизительный прогноз.
- `/edit` — выбрать день и исправить запись.
- `/undo` — отменить последнее изменение с подтверждением.
- `/reminders` — время, включение и отключение напоминаний; первоначально выключены.
- `/share` — информация о постоянном обмене.
- `/delete` — выбрать день и удалить отдельные или все его события. Периоды месячных удаляются отдельно в `/period`.
- `/erase` — очистить события и периоды с подтверждением.
- `/cancel` — отменить текущий ввод.

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Проверяются миграция старой базы, сохранность нескольких событий, редактирование/удаление/отмена, интервалы месячных, прогноз, выбор симптомов, права доступа, статистика и PNG, расписание/откладывание/повтор напоминаний. Интеграционный тест проходит реальные маршруты aiogram с локальной подменой Telegram API. Живая отправка и доставка по расписанию требуют действующего токена и работающего хостинга.
