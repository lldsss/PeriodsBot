# Машин хрю-дневничок 🐷🌷

Telegram-бот на aiogram 3. Только личные чаты Маши (1842996053) и её партнёра (1307205193).

Маша отмечает каждый день месячных, симптомы, настроение, самочувствие, близость, секс и заметки. Кнопки со свинками, календарь и приблизительный прогноз после трёх циклов. Это не медицинская рекомендация и не метод контрацепции.

Обмен выключен по умолчанию. Маша включает его через /share: партнёру открывается весь дневник и приходят новые записи. Отключение закрывает доступ. Уже доставленные сообщения в Telegram сохраняются даже после удаления дневника. Оба пользователя должны нажать /start. Неудавшиеся уведомления автоматически не повторяются.

## Запуск

Python 3.12+. Создайте бота через @BotFather. Задайте BOT_TOKEN в защищённых переменных процесса, не в Git или чате. Файлы .env автоматически не читаются.

```sh
cd /workspace/PeriodsBot
python -m venv .venv
.venv/bin/pip install -r requirements.lock
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py
```

BOT_TIMEZONE по умолчанию Europe/Moscow. BOT_DB по умолчанию data/diary.sqlite3. Храните базу и резервные копии в закрытом постоянном хранилище: приложение не шифрует SQLite. Требуется HTTPS к api.telegram.org. Запускайте один экземпляр; webhook для токена должен быть отключён.

## Команды

- /record [ГГГГ-ММ-ДД] — запись за сегодня или прошлый день; повторная запись категории заменяет прежнюю.
- /day [ГГГГ-ММ-ДД] — дневник дня.
- /calendar [ГГГГ-ММ] — календарь: М — месячные, Б — близость, С — секс.
- /forecast — приблизительный прогноз по отмеченной истории. Отмечайте каждый день месячных.
- /share — включение и отключение обмена Машей.
- /delete ГГГГ-ММ-ДД и /erase — удаление с подтверждением.
- /cancel — отмена ввода.

Тесты используют локальную SQLite и подменённый Telegram API. Реальная доставка требует токена.
